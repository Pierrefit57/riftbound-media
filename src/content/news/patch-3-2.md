# Patch 3.2 : Équilibrage et Nouvelles Cartes

Le patch 3.2 est maintenant disponible ! Voici un résumé complet des changements.

## Nouvelles Cartes

### Gardien des Flammes (Rare)
- **Type** : Créature Élémentaire
- **ATK** : 5 | **DEF** : 4
- *Quand cette carte est invoquée, inflige 2 dégâts à toutes les créatures ennemies de type Ombre.*

### Tisseuse d'Aether (Épique)
- **Type** : Mage
- **ATK** : 3 | **DEF** : 7
- *Peut copier le dernier sort joué par l'adversaire une fois par tour.*

### Sentinelle du Vide (Légendaire)
- **Type** : Constructe
- **ATK** : 6 | **DEF** : 8
- *Immunisée aux effets de banissement. Gagne +1 ATK pour chaque carte bannie cette partie.*

## Changements d'Équilibrage

| Carte | Changement |
|-------|-----------|
| Void Reaver | DEF réduite de 6 → 5 |
| Lame de l'Aube | ATK augmentée de 4 → 5 |
| Sort de Gel | Coût réduit de 4 → 3 |
| Bouclier Runique | Durée réduite de 3 → 2 tours |

## Matchmaking

- Nouveau système de rangs : Bronze, Argent, Or, Platine, Diamant, Maître
- Files d'attente séparées pour Standard et Compétitif
- Détection améliorée des joueurs AFK
