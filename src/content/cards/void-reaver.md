# Void Reaver - Legendary Card

## Abilities

**Passive - Light Eater**: All enemy creatures on the field have -2 defense while Void Reaver is active.

**Active - Rift Strike**: Deal damage equal to this card's attack to target enemy creature. If destroyed, banish it instead of sending to graveyard.

## Lore

*"In the void between worlds, there are things that should never see light. The Void Reaver is one such horror."* — Ancient Riftbound Texts

## Deck Synergies

- Shadow-based decks
- Control strategies
- Banishment mechanics
